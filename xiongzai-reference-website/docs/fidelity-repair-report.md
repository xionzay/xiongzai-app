- 重做圆润大眼鲸鱼、蓝白列车、独立浮岛和天空环境。列车名称、站台文字与路牌均由 HTML 绘制。

- 宇宙横幅恢复观景平台方向并移除全部视频相关内容；新闻缩略图改为建筑夜市、睡熊与天空城堡主题，保留筹备预告状态。
- 底部下载区使用用户提供的 613×211 原始 JPG，文件内容未改变；通过 CSS 遮罩隐藏左侧原有说明、裁去截图边缘。显示宽度不超过 613 CSS 像素，不把它称作原始高清图。
- 修复平板场景卡高度和下载区列宽；桌面仍是一排九卡，小屏仅该区域横向滚动。

## 仍存在的具体差异

1. **主要插画为依据参考图修复生成的素材。** 原始分层、相机、3D 模型和完整高清原画没有提供。熊崽脸部、具体肢体角度、企鹅造型、列车车头标识、建筑细节与云层仍不是原图逐像素一致。
2. **站台与轨道仍是二维近似透视。** 没有实现列车从远处沿弯轨驶来的三维动画。移除了此前几像素往返动画，当前列车停站；没有把停站描述为行驶。
3. **不是所有浮岛都能单独运动。** 右上方浮岛与品牌栏浮岛有独立图层；部分远景建筑与云海属于环境图片。鲸鱼、云层、泡泡、星光及光晕保留轻柔持续动效。
4. **字体仍为近似。** 使用本地 Ma Shan Zheng 手写字体，调整了行距、字距和倾斜；原图的具体笔锋、字形并未完全复现。软件 Logo 保留用户原文件，电竞组合标识与原图的轮廓版呈现仍有差异。
5. **图标为网页 SVG。** 已修正五角星、盾牌、人群等符号及渐变，轮廓与高光仍不等于参考图原始立体图标。
6. **部分普通短句做了可读性整理。** 对截图中无法可靠辨认的句子没有照抄乱码；没有恢复未核实的“平台担保、海量大神、全球领先”等能力或经营事实。
