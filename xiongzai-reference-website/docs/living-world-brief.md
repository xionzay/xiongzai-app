# 全站持续动效设计提示词

保留熊崽官网当前构图、原始手写字素材、蓝色品牌体系及用户提供的图标与周边包装。把网站设计成持续运转的云端世界，动画无需滚动触发。

- 首页：鲸鱼沿天空缓慢巡游，远近云层以不同速度循环流动，浮岛与泡泡错峰漂浮；熊崽自然呼吸、轻摆，企鹅保持站台接触；旗杆固定，旗面持续起伏。
- 列车：先分离原画中的列车与轨道，保留车身高光、轮轨关系和固定站台。列车沿透视方向前进，使用云雾遮挡循环衔接，禁止整张站台一起移动。
- 熊崽世界：九张场景卡片保持可点击与可读，图片缓慢移动并有悬停推进，场景弹窗也有环境流动。
- 关于我们：睡眠熊崽轻微呼吸；办公场景的熊崽与小猫分别轻摆，桌面和电脑保持固定，在电脑盖面加入透视匹配的苹果标志。首页公司介绍与独立公司页同步生效。
- 宇宙横幅：云雾分层漂移，星光闪烁并缓慢位移，流星间歇划过，星球光晕缓慢变化。
- 下载与页脚：云层、光线持续流动；下载按钮分别使用彩色苹果图标与绿色安卓图标，保持“即将上线”状态。
- 导航与按钮：鼠标悬停轻抬、背景亮起，直线下划线从左至右展开；键盘焦点获得相同反馈。所有动画不影响点击和滚动。
- 动画应平滑、错峰、无突跳；文字排版保持稳定。手机降低位移与粒子数量。页面隐藏、元素离屏或详情弹窗覆盖时暂停对应背景；尊重系统减少动态效果设置，提供全站暂停开关。

实现后验证桌面和手机、静止等待时的动画状态、导航悬停、下载弹窗、公司页、减少动态效果及循环衔接。
