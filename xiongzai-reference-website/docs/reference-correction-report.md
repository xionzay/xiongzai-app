- 保留真实网页的 XIONGZAI、NEXT STOP / A BRIGHTER WORLD 及站台英文；车头熊崽图案从现有列车素材中提取显示。

## 仍然存在的具体差异和限制

1. **不是原画的一比一复刻。** 没有收到整页原画的高清独立场景/角色工程文件。车站环境为按参考要求生成的新插画：城堡轮廓、远景铁路、车窗与车头细节、平台弧度与原设计稿仍不同。主熊崽和鲸鱼保留的是现有版本，姿态轮廓也不与最初截图完全相同。
2. 字稿、旗帜、水罐采用提供的原图像素，未重画；旗帜和包装是照片局部，通过原图轮廓裁切接入，不是可任意旋转的三维模型。人物轮廓同样基于已有二维素材，放大细看边缘不等同原始分层工程的精度。
3. 列车与连续轨道/平台共同停站，没有实现沿曲线真实行驶。熊崽仅轻微整体微动，不是骨骼呼吸、真实眨眼或挥手；背景里烘焙的远景城堡固定，只有独立岛屿层悬浮。
4. 九张场景、睡熊、宇宙横幅和办公熊崽都是当前项目的独立插画素材，已按环境构图方向修正，但仍与参考图内的建筑、角色细节和物件位置不同。公司办公插画不表示真实办公场所。
5. 原字体文件未提供；首页三组指定短句现直接使用原字稿，其他网页正文和标题仍使用项目字体。最新字稿与原全页图的深蓝毛笔标题不同，这是依照最新要求保留的差异。
6. 原下载列车图分辨率仅 613×211，保持原素材且不冒充高清；无真实下载地址时不能完成下载到安装包这一步。

这些限制未被计为“已像素一致还原”，也没有因区域高度接近就宣布高保真完成。
