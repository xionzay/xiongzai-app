## 已修改

1. 首页移除所有下载入口，保留标题与英文辅助文案；标题使用较纤细的中文手写/楷体网页文字，倾斜、爱心与下划线参考新增字样图。熊崽右下新增“好的游戏，总有熊崽陪伴你”。统一品牌字为“熊崽”。
2. 列车轨道重建在列车图片自身坐标系内，两股钢轨、逐渐放大的轨枕、道床与边缘结构共同缩放；重新调整手机端列车位置。列车继续停站，暖色车窗光缓慢呼吸。
3. 站台左侧新增小旗帜，旗杆与底座固定，原软件 Logo 通过 img 原样显示，旗面只做轻微角度变化。没有镜像或重新生成 Logo。
4. 熊崽右侧新增一罐铝罐概念包装，按用户罐装水参考重建，保留浅蓝山峰、云朵与熊崽包装方向；叠加原软件 Logo、接触阴影。未加入营养、认证、生产或健康宣称。
5. GSAP 分别驱动远中近云层、鲸鱼、独立浮岛、泡泡、星光、旗面、环境光。场景卡区域、宇宙横幅、下载区域和新公司页也有独立的轻柔环境动态。原生滚动，支持减少动态效果、离屏暂停和后台暂停；修复公司页往返后动效恢复。
6. 图标、按钮、卡片增加克制的悬停与点击反馈。场景图片独立放入圆角裁切容器，缩放不挤占文案。悬停与环境浮动使用不同元素。
7. 底部原下载区域加入苹果及 Android 平台矢量标识与明确的“即将上线”。按钮打开对应平台筹备说明，未设置空链接、虚假地址或二维码，不自动下载。
8. 新公司页采用办公创作空间插画，保留现有品牌理念、愿景、使命、价值观与邮箱；不增加未确认的办公地址、规模或公司经历。

## 检查结果与具体限制

| 项目 | 检查结果 |
| --- | --- |
| 无鼠标操作的背景动态 | 五种视口采样中，鲸鱼、浮岛、云层的 transform 持续变化；并非依赖鼠标或滚轮。 |
| 熊崽接触与姿态 | 现有熊崽、企鹅、背包和站台是同一张素材，保持固定；胸前仅添加轻微呼吸式光感，没有身体位移、眨眼、挥手或骨骼动画。 |
| 轨道与列车 | 已补齐轨道并在桌面、平板、手机检查前后关系；这是按现有二维列车投影绘制的轨道，不是三维轨道模拟，列车不行驶。 |
| 旗帜与水罐 | 桌面放大截图和手机截图中底座位于站台；旗面循环不遮脸，罐体未遮住脚掌；没有把道具放到铁轨上。 |
| 图标与卡片 | 检查悬停、键盘聚焦、图片容器裁切与按钮按下反馈。 |
| 八个主题场景 | 每张独立图片、左右按钮/键盘、Esc、手机滑动、滚动锁定、关闭恢复滚动与焦点通过；主城单独展示。 |
| 下载与邮箱 | 两个平台都显示即将上线，没有真实下载地址；邮箱仍是 postmaster@xionzay.com，发送与复制/失败回退通过。 |
| 响应式 | 首页 1440、1024、768、390、320px；公司页 1024、768、390、320px 检查通过，无整页横向溢出。 |
| 性能 | 本地 Chrome、无 CPU/网络节流，桌面与手机视口帧间隔中位及 P95 约16.7ms，测试期间无超过50ms帧、无长任务；手机并非实机测试。 |
| 页面与素材 | 没有视频、音频、播放按钮或无效下载链接，图片加载与运行错误检查通过。动效最大/最小位移和中间阶段留有截图。 |

字体仍无法确认原字稿的准确字体，当前保留可选中网页文字，属于近似匹配。原角色素材、浮岛与背景保持原版本；远处烘焙在背景中的建筑不能逐座独立运动。未声称已经实现真实肢体呼吸或沿曲轨运行。

水罐是参考包装重建图，不是原图精确抠出；生成工具未成功返回透明通道，所以页面使用贴合罐体的 SVG 轮廓裁切去掉背景，软件 Logo 仍为原图。公司办公图是品牌插画，不代表真实办公场所。素材提示词与来源记录在 `output/motion-brand/prompts.json`。
