## 本轮实际修正

1. **删除罐装水，删除熊崽右侧旧旗帜位置的道具。** 原包装文件留作素材存档，网页不再渲染罐体、包装或阴影。
2. **火车右侧牌子换成熊崽旗帜。** 不仅移除 NEXT STOP 网页文字，也修补了背景里烘焙的蓝色牌面和旧细杆；保留厚蓝色安全栏杆、列车、轮轨和站台。只显示一面旗帜，沿用上传原照片的旗面、金属杆和熊头顶饰。旗杆底座调整至外侧步道，旗面轻微摆动，杆件固定。
3. **修复环境光被遮盖。** 环境光原本位于首屏背景之外，新的车站层会盖住它。本轮移入首屏可见层，保留局部柔和呼吸，不覆盖整页白色滤镜。
4. **补上远景独立浮岛。** 从现有车站图的上方远景岛提取原像素轮廓，修补底图中原岛位置，再分别显示原岛层，避免叠出第二座相同岛屿。远景约 1.5px / 14秒，近景约 5px / 9秒，城堡与山体作为一组运动；有轨道连接的建筑保持固定。手机隐藏这项新增远景动态以降低复杂度。
5. **补齐轻微滚动视差。** 远云、中云与独立岛使用单独的 CSS translate，最大约 5px，与 GSAP 的持续 transform 分开，避免抢同一位移属性；只用被动滚动监听和 requestAnimationFrame，不劫持滚轮。
6. **修正品牌栏浮岛离屏暂停范围。** 不再以整个上半页可见作为播放条件，改为品牌横栏自身进入/离开视口时播放/暂停。
7. **补回新旗面悬停反馈。** 原代码只匹配旗内 img，换成 SVG 原图旗面后没有命中；现增加轻微提亮，装饰旗帜不伪装可点击按钮。

背景修补使用内置 imagegen；页面通过局部 SVG 遮罩显示修补范围，范围之外继续使用原背景，避免把重新生成的整张画面替换全页。独立浮岛和旗帜使用原素材像素，未重画人物。
