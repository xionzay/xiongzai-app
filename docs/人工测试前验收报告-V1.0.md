## 7. 本轮发现并修复的问题

1. Web 支付请求缺少 `payment_channel`，已映射为 `WECHAT_APP`/`ALIPAY_APP`。
2. Web 金额曾存在 Number/浮点换算路径，已统一为十进制分字符串和 BigInt。
3. 客服和收藏把游标响应误当数组，收藏失败还会回退演示记录，已修复为真实 `items`、加载/失败/空状态。
4. 买家订单“已退款”状态判断字段错误，已按支付状态修复。
5. Web 声音名片原为动画占位，已接入受控短时播放 URL，并补字幕轨。
6. 实时服务卡错误使用静态目录卖家“鹿野”，已改为 API 卖家事实，并按真实服务统计陪玩服务数。
7. Mobile 客服优先级曾包含服务端不存在的 `LOW`，已统一共享契约 `NORMAL/MEDIUM/HIGH/URGENT`。
8. 根后端测试命令未加载 `.env.backend.local`，导致 PostgreSQL 用例“跳过但命令成功”，已强制加载并校验独立本机测试库。
9. 管理后台浏览器 E2E 受现有 3001 开发进程锁影响，已改用隔离 3101 生产构建端口。
10. 管理后台 E2E 只应用 4 个迁移，已补齐第 5 个迁移。
11. 本机备用前端端口会错误走同源 API，已统一让所有 loopback 页面指向本地 API 3002。
12. 数据库本地验证仍要求开发库 0 行，和人工 Seed 冲突，已改为报告本地业务行数而非误报失败。
13. 新增受限、幂等、可识别的本地人工测试 Seed 和动态 TOTP 工具。
