## 4. 管理员文件模块结构

模块由导航入口、真实待审计数、文件筛选列表、文件详情抽屉、安全预览、审核操作弹窗和相关审核日志组成。API Client 统一携带 `credentials: include`，失败响应保留 HTTP 状态与业务错误码，用于区分会话失效、MFA/RBAC 拒绝和并发冲突。

## 5. 文件管理导航入口

主导航新增“文件管理 / 文件审核”。角标调用真实 `GET /admin-api/v1/files?upload_status=VERIFIED&moderation_status=PENDING&limit=100` 计算，不使用演示数字；无 `file.read` 或接口不可用时不伪造数量。

## 6. 文件列表与筛选

列表调用真实 `GET /admin-api/v1/files`，支持后端实际开放的上传状态和审核状态筛选，最大读取 100 条。展示文件 ID、所有者、用途、MIME、字节大小、图片尺寸或音频时长、上传状态、审核状态、访问级别以及更新时间。没有实现后端不支持的假分页、假搜索或假高级筛选。

## 7. 文件详情

详情展示完整文件 ID、所有者、用途、MIME、大小、媒体信息、上传状态、审核状态、访问级别和创建/更新时间。前端响应模型不包含 Bucket 或 `object_key`，页面也不渲染这些存储内部字段。

## 8. USER_AVATAR 安全预览

本段为阶段 4 历史实现，已被第三阶段安全整改取代。当前打开详情调用 `GET /admin-api/v1/files/:fileId/preview` 获取同源受控二进制；浏览器不再取得对象存储短时签名地址。

## 9. 预览 URL 安全处理

当前管理员预览链路不再向前端返回完整预签名 URL。页面只为管理 API 返回的 Blob 创建临时 `blob:` URL：

- 不写入浏览器地址栏或路由参数；
- 不写入 localStorage、sessionStorage、Cookie、数据库或操作日志；
- 不使用 `console` 输出；
- 关闭详情、重新申请或到期时清除；
- 页面不会向管理员显示 Bucket、`object_key`、Access Key 或 Secret。

## 10. 审核通过流程

只有 `VERIFIED + PENDING` 文件可以提交通过。管理员必须填写 2–1000 字符原因，提交中按钮禁用。服务端在复制后锁定数据库文件行，确认仍为待审状态，再更新为 `APPROVED`、写入一条 `FILE_APPROVED` 日志并删除隔离区源对象；公开文件进入 public Bucket，私有/签名文件进入 private Bucket。复制后若竞争失败，会清理本次多余目标对象。

## 11. 审核拒绝流程

驳回同样要求原因并只接受 `VERIFIED + PENDING`。服务端更新为 `REJECTED` 并写入一条 `FILE_REJECTED` 日志；文件不会复制到 public Bucket，公共文件接口返回不可访问，用户资料不会绑定该文件。文件所有者仍可通过受控短时访问检查隔离对象，便于后续删除或重选。

## 12. 并发审核处理

重复审核和并发审核均使用真实事务行锁与最终状态检查。两个管理员同时审核同一文件时只有一个请求成功，另一个得到 HTTP 409 和 `RESOURCE_VERSION_CONFLICT`；页面提示已被其他管理员处理并刷新真实状态。测试确认最终只有一条审核日志，不会用后到请求覆盖先成功结果。
