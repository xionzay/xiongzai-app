## 10. 推荐的最小依赖

建议仅增加三个 Expo 官方包：

1. `expo-document-picker`：通过 iOS/Android 系统文件选择器选择 AAC、M4A、MP3，返回 URI、名称、MIME 和大小。使用 `copyToCacheDirectory: true`，避免长期依赖外部 Provider URI。
2. `expo-audio`：负责录音、客户端时长预检、本地/短时地址播放和播放器释放。当前 SDK 57 本地兼容清单没有列出 `expo-av`，因此不建议为新实现新增 `expo-av`。
3. `expo-file-system`：作为直接依赖读取缓存文件字节，并精确清理由本流程创建或复制的临时文件。不得删除系统选择器原文件或未知路径。

继续复用现有 `voice-upload-domain.ts`、预签名 PUT 和文件 API；不新增第二套上传服务，不让客户端设置 Bucket 或 `object_key`。

## 14. iOS 权限要求

- 系统文件选择不需要照片库权限。
- 播放不需要麦克风权限。
- 现场录音需要 `NSMicrophoneUsageDescription`，建议文案：`用于录制 10–30 秒声音名片；录音仅在您确认后上传并进入审核。`
- 运行时必须先查询/请求录音权限；拒绝时只显示明确提示和系统设置入口，不开始录音、不伪造文件。
- 不启用后台录音；页面离开、取消或失败时停止并释放录音器。
- `expo-image-picker` 当前的 `microphonePermission: false` 可继续只负责图片权限；录音权限由 `expo-audio` 配置和运行时 API 独立管理，避免权限职责混淆。

## 15. Android 权限要求

- 现场录音需要 `android.permission.RECORD_AUDIO` 和运行时授权。
- 使用系统文档选择器选择音频，不应申请 `READ_EXTERNAL_STORAGE`、`WRITE_EXTERNAL_STORAGE` 或 `READ_MEDIA_AUDIO`；只使用系统返回的临时访问权并复制到 App 缓存。
- 播放 App 缓存文件或 HTTPS/本地开发受控地址不需要麦克风权限。
- 拒绝或永久拒绝录音权限时显示安全提示和系统设置入口。
- 不申请后台录音、全盘文件访问或与本功能无关的媒体权限。
