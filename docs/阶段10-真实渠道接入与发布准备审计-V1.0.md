# 熊崽电竞｜阶段 10 真实渠道接入与发布准备审计 V1.0

审计日期：2026-08-21；2026-08-22 补充文件存储现状复核。范围为当前未提交工作区。本报告不授权创建外部资源、产生费用、使用生产密钥、修改 DNS/生产数据库、发送真实短信、发起真实支付或打款、签名正式包或上传应用市场。

## 1. 当前结论

- **当前不得执行真实渠道切换，也不得生产发布。** 短信、支付/退款、打款均只有 Provider 接口与 Development/Mock 实现；文件上传已有本地 MinIO/S3 兼容闭环，但生产对象存储尚未创建或联调；系统推送、生产 Event Publisher、监控告警、备份/PITR、部署网关和正式签名仍未落地。
- **可以继续进行本地适配准备。** 现有生产配置已拒绝 Development SMS、Mock Payment、Mock Payout、日志 Event Publisher和移动端 HTTP/Mock Payment，适合作为后续门禁基础。
- **财务回调基础较好但尚未达到真实渠道要求。** 已具备业务幂等键、数据库唯一约束、回调事件去重、金额和业务状态核验、复式账务及 CAS；真实供应商接入前仍需实现原始报文验签、时间戳/Nonce 重放防护、证书轮换、来源网络策略、主动查单/对账和未知结果恢复。
- **本次未读取 `.env.backend.local` 的值，未发现被 Git 跟踪的环境文件或签名密钥。** `.gitignore` 已本地补充常见 iOS、Android、TLS、FCM 和服务账号密钥文件类型。

## 3. 十二项审计结果

### 3.1 预发布环境配置

**已有：** API、Mobile 和 Worker 存在生产模式安全拒绝；Mobile 生产构建要求 HTTPS 和显式应用标识；配置示例不含真实值。

**缺失/阻断：** 仓库没有可复核的 staging/production 部署清单、CI/CD、容器/IaC、网关、环境隔离证明、正式域名、证书、可安装签名包或环境晋级流程。根目录同时跟踪 `package-lock.json` 与 `pnpm-lock.yaml`，需先决定唯一包管理锁文件。

### 3.2 Secret Manager

完整清单见第 4 节。当前仅有环境变量示例，没有 Secret Manager、访问策略、密钥版本、双人审批、轮换任务或泄露应急流程。所有 `EXPO_PUBLIC_*` 均视为公开配置，禁止写入 Secret。

### 3.3 真实渠道适配器

- `SmsProvider`：只有 `DevelopmentSmsProvider`，没有真实短信供应商实现。
- `PaymentProvider`：只有 `MockPaymentProvider`；支付和退款复用同一接口。
- `PayoutProvider`：只有 `MockPayoutProvider`。
- `EventPublisher`：只有 `LoggingPublisher`，生产模式主动拒绝。
- 对象存储：已有提供商无关接口、S3 兼容/MinIO 实现及阿里云 OSS 适配边界；阿里云 SDK 适配器和任何生产 Provider 均未注入或联调。
- Push Provider、错误追踪 Exporter：没有实现。

适配器必须通过依赖注入接入，不得在 Controller/业务 Service 内写供应商 SDK 细节。供应商错误需映射为稳定内部错误码，禁止把原始报文或凭证返回给客户端。

### 3.4 支付、退款、提现和回调幂等

**已有：** 订单/支付/退款/提现使用业务幂等键或唯一活动约束；支付事件和 Inbox 有数据库去重；回调核验金额、渠道编号和状态；状态更新使用事务、行锁/CAS；账务使用唯一幂等键和复式平衡。

**真实渠道前必须补齐：** 当前回调仅为 `/callbacks/v1/*/mock`，签名是对解析后 JSON 做 HMAC，不适用于多数真实渠道的原始报文/证书签名。需要供应商专用路径、原始 Body、时间戳与 Nonce、防重放窗口、证书/公钥版本、IP 策略、回调限流、固定成功响应、乱序事件策略、主动查单、日终对账、差错队列和人工修复审计。Provider 的创建支付/打款/退款必须以平台单号作为供应商幂等标识，并处理“请求超时但渠道可能已受理”的未知结果，不能直接当作确定失败。

### 3.5 对象存储和文件安全

**已有：** `files`、`file_usages` 和生命周期任务模型；服务端策略、短时预签名 PUT、complete、HEAD/读取、SHA-256、真实 MIME、图片尺寸与音频时长校验、本人恢复列表、删除、审核、公开/受控访问和业务引用校验；公开读取只允许 VERIFIED + APPROVED + PUBLIC。Mobile 已接入用户/陪玩头像、封面、商品图、投诉证据和声音名片。上述链路已有本地 MinIO 与注入 Provider 自动化证据。

**缺失/阻断：** 未创建或连接预发布/生产 OSS Bucket、IAM/KMS、正式访问域名和 CDN；阿里云 OSS SDK 适配器未实现真实联调；病毒/恶意文件扫描、自动内容安全、图片重编码、CDN 缓存失效和生产恢复演练仍缺失。本机 MinIO 仅监听回环地址，Android 模拟器和真机不能直接复用其 `127.0.0.1` 预签名 URL。身份证等敏感文件必须使用独立私有策略，不得复用公开头像链路。

### 3.6 推送、权限和深链

**已有：** 数据库预留设备 Push Token 密文/哈希和通知投递日志；App 内通知、已读、关联资源权限检查和内部路由映射已存在。

**缺失/阻断：** Mobile 未安装通知 SDK，未申请通知权限，没有 Token 注册/轮换/注销 API，没有 APNs/FCM Provider/Worker、静默推送策略、退订偏好、失效 Token 清理、Associated Domains、Universal Link、Android App Link 和站点声明文件。推送 Payload 只允许最小标识，不得携带 Token、手机号、聊天正文或财务敏感内容；点击后仍须向服务端鉴权取数。

### 3.7 TLS、CORS、Cookie、Bearer、CSP 和网关

**已有：** CORS 使用显式 Origin 清单并允许凭证；Cookie 为 HttpOnly/SameSite，生产增加 Secure；Cookie 写请求校验 Origin/Sec-Fetch-Site；Mobile Bearer Session 校验签名、issuer、audience 和服务端 Session；生产移动认证拒绝 HTTP。

**缺失/风险：** `trustProxy: true` 但没有可信代理网段配置，API 不能直接暴露公网；没有仓库内可验证的 TLS 终止、HSTS、Helmet/安全响应头、CSP、请求体大小、全局/短信/认证/回调限流、WAF、DDoS、超时和网关日志策略。生产网关必须全站 HTTPS，剥离外部伪造的 Forwarded 头，并仅由可信代理重新写入。CSP 主要作用于 Web 管理端和 Web 用户端，原生 App 不以 CSP 代替客户端安全。

### 3.8 数据库备份、PITR 和恢复

当前只有迁移和隔离测试 Schema，没有备份、PITR、跨区域副本、备份加密/留存、恢复账号、恢复演练证据或冻结的 RPO/RTO。生产前必须定义订单/账务优先恢复顺序；恢复不得通过回滚已发生的支付、退款、提现事实完成，恢复后必须跑账务平衡、渠道对账、Inbox/Outbox 和 Scheduled Job 一致性检查。

### 3.9 日志、指标、告警和错误追踪

**已有：** JSON 日志、request/trace ID、按字段名递归脱敏、异常仅记录名称，Token 类接口 no-store；健康检查已存在。

**缺失/阻断：** 没有集中日志、日志留存与访问审计、OpenTelemetry/指标 Exporter、Sentry 类错误追踪、隐私 Scrubber 配置、SLO、告警路由和值班表。至少需要 API 错误率/延迟、登录失败、短信送达、支付/退款/提现回调延迟和失败、对账差异、Outbox/Inbox/Scheduled Job 堆积、数据库连接/锁/复制延迟、对象扫描失败、Push 失效率等指标。

### 3.10 iOS/Android 签名与构建

**已有：** Expo Prebuild/Development Build，应用标识通过环境变量注入，生产配置拒绝缺失标识；常规 iOS/Android Bundle 导出已通过。

**缺失/阻断：** 没有最终 Bundle ID/Application ID、Apple Team、证书/Profile、Android keystore/alias、EAS 或本地 CI 凭证托管、build number/version code 策略、签名 Release 构建、SBOM、产物校验和真机证据。当前自定义 Scheme 不能替代 Universal/App Link。

### 3.11 隐私、权限和商店材料

**已有：** 当前只声明相册/相机用途，麦克风不申请，系统推送未接入时不申请通知；App 锁定浅色模式并如实记录；协议版本和接受记录由服务端保存。

**缺失/阻断：** 最终隐私政策 URL、用户协议 URL、公司主体、客服与投诉渠道、数据收集/共享/删除说明、第三方 SDK 清单、Apple Privacy Manifest/App Privacy、Google Data Safety、分级和内容审核说明、截图/预览视频、应用描述、版权材料、审核测试账号及注销/数据导出真实能力。引入每个真实 SDK 后必须重新核对权限和数据流。

### 3.12 灰度、回滚与 Go/No-Go

现有阶段 9 手册只有原则性流程，没有生产流量切分、Feature Flag/Kill Switch、渠道开关、最低支持版本、API 向后兼容窗口、DB Expand/Contract 迁移、值班表和可执行回滚自动化。客户端回滚不能撤销服务端财务事实；支付、退款、提现开关必须可独立关闭，同时保留查询、回调和对账能力。

## 4. Secret Manager 变量清单

下列只定义名称和用途，不包含值。名称可在云平台落地时增加环境前缀；生产与预发布必须使用不同项目、密钥和值。

### 4.1 当前后端必需

| Secret/配置 | 类型 | 使用者 | 轮换要求 |
|---|---|---|---|
| `DATABASE_URL` | Secret | API/Worker/Scheduler/Migration Job | 独立最小权限账号；轮换需连接池滚动重启 |
| `USER_TOKEN_SECRET` | Secret | API | 支持双 Key 验证窗口后轮换 |
| `ADMIN_TOKEN_SECRET` | Secret | API | 与用户/内部 Token 分离；双 Key 轮换 |
| `INTERNAL_TOKEN_SECRET` | Secret | 内部服务 | 服务间独立，定期轮换 |
| `CURSOR_SIGNING_SECRET` | Secret | API | 轮换期间兼容旧 Cursor 或接受短时失效 |
| `PII_ENCRYPTION_KEY` | 高敏 Secret/KMS | API | 必须有 key version；轮换需后台重加密任务 |
| `PII_HMAC_KEY` | 高敏 Secret | API | 轮换会影响查询索引，需双哈希迁移方案 |
| `AUTH_HMAC_KEY` | 高敏 Secret | API | Refresh Token/验证码域隔离；轮换需 Session 策略 |

`NODE_ENV`、主机端口、连接池、TTL、Origin、Issuer/Audience、Provider Mode、Worker/Scheduler 批次等是受控配置，不是 Secret，但必须由环境配置管理，不能由请求覆盖。

### 4.2 供应商确定后新增

| 类别 | Secret/配置占位 | 注意事项 |
|---|---|---|
| 短信 | `SMS_PROVIDER_API_KEY`、`SMS_PROVIDER_API_SECRET`、签名/模板 ID、回调验签材料 | 模板 ID 可为配置；密钥只在 API/短信 Worker 使用 |
| 支付/退款 | 商户号、应用 ID、API Key、商户私钥、平台证书/序列号、回调解密 Key | 私钥优先 KMS/HSM；证书支持并行轮换；客户端不持有商户私钥 |
| 打款 | 商户/企业账号、API Key/证书、账户校验凭证、回调验签材料 | 与收款账户密文密钥分离；仅提现 Worker 可读 |
| 对象存储 | 服务账号/Workload Identity、Bucket、KMS Key、CDN Origin 凭证、URL 签名 Key | 优先无长期 Access Key；公私桶和权限隔离 |
| 推送 | APNs Key ID/Team ID/`.p8`、FCM 服务账号或 Workload Identity | 客户端只含公开配置；服务端凭证最小权限 |
| 事件系统 | Broker URL、Producer/Consumer 凭证、TLS CA | 每服务独立账号和 Topic ACL |
| 监控 | Error Tracking DSN/Token、OTLP Endpoint 凭证、告警 Webhook | Mobile DSN 视为公开标识但仍需限流；服务端管理 Token 属 Secret |
| DNS/TLS | DNS 自动化 Token、ACME/证书私钥 | 若使用云托管证书，避免导出私钥 |
| iOS 签名 | Distribution 证书、Provisioning Profile、App Store Connect API Key | 只允许签名 Job 使用；不得落入源码或通用 CI 日志 |
| Android 签名 | Keystore、alias、store/key password、Play API 服务账号 | Keystore 双份加密备份；密码与文件分开托管 |
| 数据库备份 | 备份服务账号、备份 KMS Key、跨区域复制权限 | 与应用运行账号分离；恢复账号默认禁用 |

| EXT-07 | 创建 APNs/FCM 项目并发送推送 | 采集设备 Token 并触达用户 | 通常账号/平台费用待确认 | 关闭推送 Worker；撤销 Token/证书并清理设备 Token | 未批准 |
| EXT-08 | 创建监控、日志和告警项目 | 传输运行数据，可能含受控元数据 | 待日志量与留存报价 | 停止 Exporter、撤销 Token、按策略删除数据 | 未批准 |
| EXT-09 | 修改 DNS、申请证书、发布关联域文件 | 改变公网路由和深链归属 | 待域名/CDN报价 | 恢复原 DNS；撤回关联文件；证书吊销需审慎 |
| EXT-10 | 使用 iOS/Android 正式签名生成候选包 | 形成可分发的受信任产物 | 账号年费/签名服务费待确认 | 撤销证书/Profile/密钥；停止分发，不可撤回已安装包 |
| EXT-11 | 上传应用商店并提交审核/发布 | 对外披露应用和材料 | 商店账号费用待确认 | 审核前撤回；发布后下架/停止灰度，但用户已安装版本仍存在 |
| EXT-12 | 生产恢复或低额真实交易演练 | 操作生产数据或真实资金 | 交易费与人工成本待确认 | 按演练 Runbook 止损；财务事实只能冲正/退款，不能删除 |

## 7. Go/No-Go 检查表

### 进入供应商沙箱联调

- [ ] 供应商、产品、沙箱、费率、合规和负责人已确定。
- [ ] 预发布项目、域名、隔离数据库、Secret Manager 和最小权限已批准。
- [ ] Provider 适配器、契约测试、超时/重试/未知结果和回调重放测试通过。
- [ ] 测试数据、白名单手机号、沙箱资金和文件不含生产 PII。

### 进入生产候选

- [ ] 十二项审计中的 P0 全部关闭并有证据链接。
- [ ] 备份/PITR 恢复演练达到冻结的 RPO/RTO，恢复后账务与渠道对账一致。
- [ ] 双平台签名构建、真机、可访问性、弱网、安全和 12 条 UI E2E 通过。
- [ ] 日志脱敏、错误追踪、SLO、P0/P1 告警和 24 小时值班演练通过。
- [ ] 隐私政策、协议、注销、数据导出、权限说明和商店材料完成法务/产品确认。

### 允许正式发布

- [ ] 灰度比例、观察时长、Kill Switch、最低版本和回滚责任人已冻结。
- [ ] 短信、支付、退款、提现、文件、推送和对账在受控生产演练通过。
- [ ] 产品、技术、安全、财务、客服、隐私/法务共同签署 Go。
- [ ] 发布动作获得单独明确批准；未把预发布批准视为生产发布批准。

## 8. 下一步边界
