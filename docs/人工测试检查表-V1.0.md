## D. 陪玩链路

- [ ] 已通过陪玩可以进入陪玩中心，待审核账号受到限制。
- [ ] 接单、开始服务、标记完成均按状态机执行。
- [ ] 非法跳转和旧 version 被拒绝。
- [ ] 收益从待结算变为可用，金额无浮点误差。
- [ ] 微信/支付宝收款账户只展示脱敏值。
- [ ] 两个并发提现不能锁定同一收益。
- [ ] Mock 提现成功/失败不会真实打款，失败会释放锁定收益。
- [ ] 有效欠款或高风险状态会暂停提现。

## E. 售后与财务一致性

- [ ] 两次历史部分退款可以串行完成。
- [ ] 同时只能存在一个有效退款流程。
- [ ] 累计退款金额不超过实付金额。
- [ ] 重复退款回调不重复退款、不重复记账。
- [ ] 评价隐藏/恢复会重算评分汇总。
- [ ] 每个订单只有一条主收益。
- [ ] 所有 POSTED 账务事务借贷平衡且至少有两条分录。
- [ ] 冲正新增反向事务，不修改历史分录。
- [ ] 已提现订单退款会创建欠款，后续收益按 FIFO 抵扣。
- [ ] 用户端和后台同一订单的编号、状态、支付状态、退款额一致。
- [ ] Outbox 与业务事务一致；重复消费不重复通知或记账。
