# 熊崽电竞身份与用户模块 V1.0

## 1. 范围

本模块实现手机号短信登录、用户会话、个人资料、隐私设置、协议接受和实名认证。数据只使用现有 `users`、`user_profiles`、`identity_verifications`、`auth_sessions`、`sms_codes`、`user_devices`、`privacy_settings`、`policy_versions`、`user_policy_acceptances` 表。

本阶段不接入付费短信渠道，不实现手机号换绑、账号注销和个人数据导出任务。

## 2. Public API

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| POST | `/api/v1/auth/sms/send` | 公开 | 发送登录验证码；响应不包含手机号或验证码 |
| POST | `/api/v1/auth/sms/login` | 公开 | 验证码登录/注册；Access、Refresh Token 通过 HttpOnly Cookie 下发 |
| POST | `/api/v1/auth/token/refresh` | Refresh Cookie | 原子轮换 Refresh Token |
| POST | `/api/v1/auth/logout` | 用户 | 撤销当前会话并清除 Cookie |
| GET | `/api/v1/me` | 用户 | 当前用户、资料、脱敏手机号和实名状态 |
| PATCH | `/api/v1/me/profile` | 用户 | 使用用户和资料双 version 更新资料 |
| GET | `/api/v1/me/privacy-settings` | 用户 | 查询隐私设置 |
| PATCH | `/api/v1/me/privacy-settings` | 用户 | 使用 version 乐观锁更新隐私设置 |
| GET | `/api/v1/me/sessions` | 用户 | 查询登录会话和设备摘要 |
| DELETE | `/api/v1/me/sessions/{session_id}` | 用户 | 撤销本人指定会话 |
| GET | `/api/v1/me/identity-verification` | 用户 | 查询最新实名认证脱敏状态 |
| POST | `/api/v1/me/identity-verification` | 用户 | 提交人工审核实名认证 |
| GET | `/api/v1/policies/current` | 公开 | 每类协议的最新已发布版本 |
| POST | `/api/v1/policies/acceptances` | 用户 | 保存不可变协议接受记录 |

## 3. Admin API

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/admin-api/v1/identity-verifications` | `identity.read` + MFA | 按状态查询脱敏实名记录 |
| POST | `/admin-api/v1/identity-verifications/{id}/review` | `identity.review` + MFA | version 乐观锁审核，并写管理员审计和 Outbox |

## 4. 安全规则

- 手机号、姓名和证件号使用 AES-256-GCM 分域加密；查询使用独立密钥的 HMAC-SHA256；数据库另存脱敏展示值。
- 验证码和 Refresh Token 只保存分域 HMAC，不保存可还原明文。
- 用户 Token 不进入 JSON、localStorage 或普通日志，只通过 HttpOnly、SameSite Cookie 传输；生产环境增加 `Secure`。
- 登录、资料、隐私、实名和审核响应只返回脱敏数据；后台审核列表也不能读取密文。
- 验证码有发送间隔、有效期、最大错误次数和一次性消费约束。
- Refresh Token 每次使用后原子轮换；退出、设备撤销、会话过期和用户封禁都会使访问失效。
- 资料、隐私和实名审核使用 `id/status/version` Compare-And-Set；冲突返回 `RESOURCE_VERSION_CONFLICT`。
- 实名审核只记录状态、操作者、原因、请求和 Trace，不把姓名或证件写入管理员操作日志。

## 5. 配置

新增必填密钥：`PII_ENCRYPTION_KEY`、`PII_HMAC_KEY`、`AUTH_HMAC_KEY`，均至少 32 字节。开发环境使用 `SMS_PROVIDER_MODE=development`；生产环境禁止使用该模式，必须注入真实 Provider。

本地开发配置保存在 Git 忽略且权限为 `0600` 的 `.env.backend.local`。任何验证码、Token、密钥和完整连接串不得输出到终端、日志或提交到 Git。
