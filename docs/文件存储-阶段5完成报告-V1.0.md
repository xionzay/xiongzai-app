## 5. 通用图片上传协调器

已完成。领域层统一处理策略查询、字节读取、空文件/MIME/大小校验、SHA-256、上传申请、原始 PUT、确认、取消和安全重试；UI 槽位组件统一处理图片选择、任务状态、待审恢复和绑定回调。

PUT 只使用服务端返回的必要请求头，不携带登录 Bearer。PUT 成功而确认失败时只重试确认，不自动重复上传；PUT 尚未成功时才尽力删除待上传记录。预签名 URL 不持久化、不记录日志，也不作为错误文本返回。

## 6. 本人文件列表接口

已新增 `GET /api/v1/me/files`。接口要求登录，只根据认证用户 ID 查询，并支持用途、上传状态、审核状态、限制和签名 Cursor 分页。响应只包含安全业务字段，不返回 Bucket、对象键、存储 Endpoint、密钥或预签名 URL。

未登录、跨用户、筛选、分页和响应字段安全均有测试。

## 7. 待审任务恢复

已完成。各图片入口打开时从本人文件接口读取服务端事实：

- `PENDING`：允许删除记录并重新选择。
- `UPLOADED`：只重试确认，不重复 PUT。
- `VERIFIED/PENDING`：显示等待审核并允许刷新。
- `APPROVED`：进入业务绑定。
- `REJECTED`、`FAILED`：允许删除并重新选择。
- `DELETED`：不恢复。

恢复不依赖本地缓存猜测，取消和组件卸载会阻止迟到的状态更新。
