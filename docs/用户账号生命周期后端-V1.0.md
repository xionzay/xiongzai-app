# 熊崽电竞｜用户账号生命周期后端 V1.0

## 1. 本地范围

本模块只用于本地完整测试。短信使用 Development SMS；导出对象写入本地私有 MinIO；不接真实短信、云存储、电子签、推送或其他付费服务。用户端和后台页面不在本次修改范围内。

## 2. 手机号换绑

接口：

- `POST /api/v1/me/phone-change-requests`，请求头必须包含 `Idempotency-Key`，正文为 `new_phone`。
- `GET /api/v1/me/phone-change-requests`。
- `POST /api/v1/me/phone-change-requests/:id/old-code/send`。
- `POST /api/v1/me/phone-change-requests/:id/old-code/verify`，正文为 `code`、`version`。
- `POST /api/v1/me/phone-change-requests/:id/new-code/send`。
- `POST /api/v1/me/phone-change-requests/:id/new-code/verify`，正文为 `code`、`version`。
- `POST /api/v1/me/phone-change-requests/:id/cancel`，正文为当前 `status`、`version`。

旧号码验证码用途固定为 `PHONE_CHANGE_OLD`，新号码固定为 `PHONE_CHANGE_NEW`。验证码一次性消费，错误次数受限。所有请求状态更新均使用 `id + status + version` CAS。新号码验证成功时，`users`、换绑请求、全部用户 Session 撤销和 Outbox 在同一事务提交；客户端必须清除本地 Token 并重新登录。

## 3. 个人数据导出

接口：

- `POST /api/v1/me/data-exports`，请求头必须包含 `Idempotency-Key`。
- `GET /api/v1/me/data-exports`。
- `GET /api/v1/me/data-exports/:id/download`。

创建请求只入队 `PERSONAL_DATA_EXPORT_GENERATE`，HTTP 请求不生成大文件。Scheduler 通过服务端白名单生成 JSON，排除 Token、验证码、密钥、手机号明文、风控内部信息及他人数据。文件必须为 `DATA_EXPORT`、`SIGNED`、私有 Bucket，并以 `EXPORT + USER` 绑定。下载 URL 每次鉴权后在运行时短时生成，不写入数据库、日志或 Outbox。

到期任务 `PERSONAL_DATA_EXPORT_EXPIRE` 将导出标记过期、软删除文件和绑定，并复用 `FILE_OBJECT_DELETE` 清理对象。

## 4. 账号注销

接口：

- `POST /api/v1/me/account-cancellations`，请求头必须包含 `Idempotency-Key`，正文为 `reason`。
- `GET /api/v1/me/account-cancellations`。
- `POST /api/v1/me/account-cancellations/:id/revoke`，正文为 `version`。
- `GET /admin-api/v1/account-cancellations`，需要 MFA 和 `user.read`。
- `POST /admin-api/v1/account-cancellations/:id/reject`，需要 MFA 和 `user.manage`，正文为 `version`、`reason`。

服务端检查未完结订单、退款、投诉、提现、陪玩余额和欠款，阻塞时返回 `ACCOUNT_CANCELLATION_BLOCKED` 与 `blocker_codes`。冷静期优先读取有效平台配置 `account_cancellation_waiting_seconds`，本地缺省为 7 天并固化在申请记录上。

到期任务复用 `scheduled_jobs`。任务再次检查阻塞条件，以 CAS 进入处理状态；用户状态、注销请求状态、全部 Session 撤销和 Outbox 同事务完成。`users.cancelled_at` 与请求 `completed_at` 使用同一个时间对象。管理员拒绝日志的 `action` 固定以 `ACCOUNT_CANCELLATION_` 开头，`target_type=USER` 且指向对应用户。

## 5. 错误与安全

- `PHONE_CHANGE_ALREADY_ACTIVE`、`PHONE_CHANGE_EXPIRED`、`PHONE_ALREADY_BOUND`。
- `DATA_EXPORT_ALREADY_ACTIVE`、`DATA_EXPORT_NOT_READY`。
- `ACCOUNT_CANCELLATION_ALREADY_ACTIVE`、`ACCOUNT_CANCELLATION_BLOCKED`。
- `COMPLAINT_EVIDENCE_LIMIT_REACHED`：投诉已有 20 条证据。
- 并发或过期版本统一返回 `RESOURCE_VERSION_CONFLICT`。

手机号密文、验证码、导出内容和短时 URL不得写入普通日志、审计快照或 Outbox。生命周期请求和历史证据禁止物理删除。
