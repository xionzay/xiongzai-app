# 熊崽电竞公司官网 UI 设计图说明

本目录包含 14 张通过内置图像生成能力制作的官网 UI 概念图，统一参考项目现有熊崽电竞 Logo、吉祥物与蓝色品牌体系。

## 推荐组合

- 首页：`13-桌面端-首页审核修正版.png` + `05-移动端-首页.png`
- 产品页：`02-桌面端-熊崽电竞产品页.png` + `06-移动端-熊崽电竞产品页.png`
- 用户支持：`03-桌面端-用户支持中心.png` + `07-移动端-用户支持中心.png`
- 隐私与账号：`11-桌面端-隐私政策.png` + `08-移动端-隐私与账号中心.png`
- 投诉举报：`10-桌面端-投诉与举报.png`
- 公司介绍：`04-桌面端-关于我们.png`
- 视觉规范：`12-官网设计系统.png`

## 只参考布局的图片

- `01-桌面端-首页初稿.png`：包含生成模型自动补出的示意数据与备案号，不能直接使用。
- `09-桌面端-应用下载页初稿.png`：手机界面偏赛事产品，和熊崽电竞实际定位不一致。
- `14-桌面端-应用下载页修正版.png`：整体布局可用，但手机界面仍包含生成的价格、人物和功能文案，开发时必须替换为真实 App 截图。

## 统一生成要求

- 公司官网以“可信、清楚、便于审核”为主，保留适度电竞品牌感。
- 颜色使用品牌蓝 `#278FE8`、深蓝 `#155E9F`、强调橙 `#FF5A24`、暖白 `#FFF9EF` 和正文色 `#181A1F`。
- 页面覆盖首页、产品、支持、隐私、账号注销、投诉举报、下载、关于我们和设计系统。
- 不使用第三方游戏 Logo、角色或官方合作暗示。
- 不生成真实联系方式、备案号、认证、运营数字或审核承诺。
- 所有图片中的文字和数据均为视觉示意，开发上线时以法务确认和真实资料为准。

## 开发时的硬性替换项

1. 使用项目中真实的 App 截图，不照抄生成图中的人物、价格、订单或活动内容。
2. 公司名称、地址、电话、邮箱、工作时间必须与真实资料一致。
3. ICP/APP/公安备案信息只能在取得后展示。
4. 隐私政策、SDK 清单、个人信息收集清单和账号注销说明必须与正式 App 数据流一致。
5. 未上架前下载页仅展示“即将上线”，不生成虚假商店徽章或二维码。
