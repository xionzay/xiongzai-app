# 熊崽电竞官网动态视觉方案说明

## 推荐组合

正式官网不建议整套照搬单张效果图，推荐组合使用：

- 首页结构与留白：`01-极简白色产品型`
- 产品展示区：`03-产品展示市场型`
- 熊崽品牌视觉与蓝色空间感：`04-蓝色玻璃空间型`
- 公司信息、规则和页脚：`02-公司可信编辑型`
- 首屏滚动氛围：参考 `06-深蓝电影叙事型`，但降低水面效果的复杂度
- 动效节奏：参考 `07-滚动动效分镜` 与 `08-官网动效系统`

这套组合可以同时兼顾公司可信度、页面简洁度、产品展示效果和熊崽电竞的品牌识别。

## 八张设计图的用途

1. **极简白色产品型**：最接近简洁、高级、审核友好的公司产品官网，适合作为最终首页骨架。
2. **公司可信编辑型**：公司感最强，适合公司介绍、平台规则、用户支持、隐私与资质入口。
3. **产品展示市场型**：产品内容最丰富，适合展示服务发现、沟通、订单管理等产品流程。
4. **蓝色玻璃空间型**：品牌视觉最统一，适合首页首屏和重要产品展示区。
5. **暖白品牌编辑型**：年轻、有个性，熊崽形象突出，适合品牌故事或活动型首页。
6. **深蓝电影叙事型**：视觉冲击和滚动氛围最强，适合用作首屏动效参考。
7. **滚动动效分镜**：展示从首屏到产品区的连续运动关系，只参考动效，不使用图中的赛事文案。
8. **官网动效系统**：展示导航、标题、熊崽、手机、卡片和无障碍模式的统一运动规则。

## 推荐滚动动效

### 首屏

- 标题按行进入：透明度从 0 到 1，向上移动 24px，持续 600ms。
- 熊崽角色轻微视差：页面向下滚动时，角色缓慢上移 30–40px。
- 手机模型从右侧进入：旋转从 10° 回正，缩放从 1.06 到 1，避免夸张翻转。
- 蓝色背景光斑采用非常缓慢的漂移，不使用自动播放声音。

### 从首屏进入产品区

- 首屏保持短暂固定，手机留在画面中心，文字先淡出，产品卡片再进入。
- 产品卡片每张间隔 80ms 依次出现，从下方 36px 上移并淡入。
- 背景从深蓝自然过渡到白色，不做突然切屏。
- 可使用圆角遮罩扩张效果，让白色产品区像一张卡片覆盖上来。

### 产品展示区

- 中间手机保持固定，左右功能说明随着滚动依次切换。
- 每段只突出一个功能：找服务、沟通确认、订单管理、售后与规则。
- 卡片悬停仅上移 6px，并增加柔和阴影，持续 220ms。
- 手机界面切换使用淡入和轻微位移，不使用复杂 3D 翻转。

### 公司与合规信息区

- 公司介绍、用户支持、服务协议、隐私政策、未成年人保护等区域以稳定为主。
- 只使用轻微淡入，不使用视差、漂浮或高速动画。
- 页脚必须清晰展示公司主体、联系方式和各项政策入口。

### 动效适配

- 手机端减少固定滚动区，避免页面卡顿和内容难以操作。
- 支持系统“减少动态效果”设置；开启后取消视差、旋转与固定滚动，只保留淡入或直接显示。
- 动效不应遮挡按钮，也不能延迟用户进入协议、隐私政策、客服和下载入口。

## 正式制作时需要替换的内容

- 设计图中的手机界面均为视觉示意，必须换成熊崽电竞真实或本地模拟的产品界面。
- 动效分镜中出现的赛事、数据等文案仅表示卡片运动方式，应改为陪玩服务发现、沟通、订单、退款与售后内容。
- 不使用虚构用户数量、合作伙伴、认证、备案号、评分或服务保证。
- 不出现第三方游戏商标、游戏角色或未经授权的素材。
