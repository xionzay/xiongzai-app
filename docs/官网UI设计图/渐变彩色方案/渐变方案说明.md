# 熊崽电竞官网渐变彩色方案

## 核心品牌表达

首页第一信息不再是功能列表，而是熊崽电竞的使命：

> 让每个人都能创造价值

推荐首屏排版：

```text
让每个人都能
创造价值
```

推荐辅助文案：

> 连接热爱、服务与机会，让清晰的信息、便捷的沟通和完整的记录，帮助每一份能力被看见。

## 最终推荐组合

- 页面结构与可读性：采用 `02-青蓝极光产品型`
- 首屏色彩饱满度：采用 `01-蓝紫玫红霓虹型`
- 各板块的颜色变化：采用 `04-彩色编辑价值型`
- 深色品牌展示区：局部采用 `05-深色霓虹可信型`
- 滚动过程：采用 `06-渐变滚动动效分镜`

不建议整站一直使用深色霓虹。首屏可以浓烈，进入公司信息、用户支持、协议、隐私政策和未成年人保护区域后，应回到浅色背景，以保持可信度和阅读体验。

## 滚动动效方案

1. **首屏固定**：首屏保持约 120vh 的滚动距离，背景为蓝紫玫红渐变。
2. **使命文字**：第一屏完整显示；滚动后轻微缩小并向左上移动，不能突然消失。
3. **熊崽视差**：熊崽以页面滚动速度的约 0.6 倍移动，制造前后景关系。
4. **渐变变色**：背景从蓝紫玫红过渡为紫粉橙，再进入青蓝浅色产品区。
5. **手机固定**：滚动到 45%–65% 时手机保持在画面中心，内部界面依次切换。
6. **产品卡片**：发现服务、沟通确认、订单管理、用户支持四张卡片，每张间隔 80ms 进入。
7. **导航变化**：首屏为透明导航，滚动 24px 后变为半透明磨砂导航。
8. **浅色信息区**：公司介绍和合规板块只使用轻微淡入，不使用复杂视差。
9. **减少动态效果**：系统开启减少动态效果时，取消固定滚动、旋转和视差，只保留淡入与渐变切换。

## 需要注意

- 彩色不等于每个元素都用渐变。正文、协议和支持内容保持深色文字及浅色背景。
- 一个屏幕最多保留一个主要渐变焦点，其余卡片用半透明白色或单色承接。
- 手机界面和服务内容均为设计示意，正式制作时换成熊崽电竞真实或本地模拟界面。
- 不使用虚构收入、用户数量、评分、认证、备案号、合作伙伴或保证性表述。
- 不出现第三方游戏名称、游戏角色和未经授权的商标。
