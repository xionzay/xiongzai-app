- 买家首页：`http://localhost:3001/` 的“01 买家首页”
- 陪玩主页：`http://localhost:3001/` 的“02 陪玩主页”

## 图片不重复规则

- 买家首页：只使用上一批头像中的独立图片。

- 三个页面之间不得共享任何人物头像或订单缩略图。
