## 三台手机展示内容

- 左侧：首页真实 UI，首页卡片头像使用独立素材。
- 中间：陪玩主页真实 UI。
- 右侧：我的订单真实 UI，展示不同服务标题、规格和价格。
- 三个页面不显示时间、电量、信号或 Wi-Fi 状态栏。
- 首页、陪玩主页、订单页的人物图片互不重复。

`08` 最终版保留原图中的手机外壳、透视角度、背景、熊崽人物、标题、侧边编号、保障区、页脚和下载入口；只在原有手机屏幕范围内叠放真实用户端页面。

## 四个订单

1. 经典模式｜欢乐四排陪伴；四排开黑 · 稳定沟通；¥25.00。
2. 地铁模式｜摸金路线熟悉；摸金撤离 · 路线指导；¥30.00。
3. 经典模式｜默契双排沟通；双排配合 · 欢乐上分；¥45.00。
4. 地铁模式｜战备物资指导；物资规划 · 进阶指导；¥60.00。

正式修正版不显示分钟、日期、预约时段或任何服务时间信息；首页固定显示两个陪玩卡片。

## 真实用户端组件

最终版的三个屏幕来自 `app/website-ui-preview`，直接使用用户端现有的全局样式与组件类名：

- 首页：`home-screen`、`shop-card`、`buyer-nav`。
- 陪玩主页：`companion-screen`、`store-hero`、`store-stats`、`voice-card`。
- 我的订单：`orders-screen`、`buyer-order-card`、`buyer-nav`。

该本地官网展示层不会修改正常用户端的接口、数据或业务流程。

修正版采用用户上传的原始头像文件与 HTML 文字图层，没有用生成式图片重画头像、标题、规格或价格。
