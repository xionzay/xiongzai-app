# 官网展示 UI 对照说明

## 对照来源

本版以本地用户端 `http://localhost:3001/` 的三个核心页面为唯一界面结构参考：

1. 买家首页
2. 陪玩主页
3. 服务详情

浏览器检查时保存的原始页面参考位于上一级目录的“真实UI页面参考”文件夹。

## 官网三台手机的固定对应关系

- 左侧手机：买家首页
  - 熊崽电竞标志
  - 橙色描边搜索框
  - 推荐、陪玩、服务切换
  - 宣传横幅
  - 热门陪玩、热门服务
  - 首页、订单、消息、我的底部导航
- 中间手机：陪玩主页
  - 返回、标题、分享
  - 大幅陪玩资料卡
  - 数据统计栏
  - 声音名片
  - 关于我、全部服务
  - 收藏陪玩、咨询陪玩
- 右侧手机：服务详情
  - 返回、标题、分享
  - 服务封面与分类标签
  - 服务名称、价格、规格
  - 陪玩资料卡与服务说明
  - 咨询、收藏服务、选择规格

## 约束

- 官网展示的用户端 UI 不得重新发明布局，必须继续以本地真实页面为准。
- 可以替换头像、昵称、服务标题、价格等演示内容，但不能改变组件结构和主要交互位置。
- 本轮仅更新设计参考图，没有修改用户端代码，也没有接入真实接口、服务器或软件下载地址。

## 生成方式

使用内置 ImageGen，将真实页面截图作为界面结构参考，将上一版官网长页作为编辑目标；提示词要求保留官网整体视觉，只替换三台手机中的用户端界面，并明确分配 ¥25、¥30、¥45、¥60 四档价格。
