# 熊崽电竞官网参考图动态版

本次版本根据用户提供的长页参考图重新收紧官网视觉，并保持页面为真实、响应式的 HTML/CSS/JavaScript 实现。

## 本次修改

- 重做蓝紫宇宙首屏，保留熊崽电竞品牌、蓝色熊崽与使命“让每个人都能创造价值”。
- 增加贯穿页面的 01「使命」、02「产品体验」、03「支持与保障」章节轨道与滚动进度。
- 产品区域使用三台独立立体手机，分别展示真实用户端首页、陪玩主页和订单页面；未使用整张长图充当网页。
- 保留首页两个陪玩、陪玩主页资料和四个订单；订单价格为 ¥25、¥30、¥45、¥60。
- 下载区增加 Apple 版、Android 版和网页版三个入口；当前均为本地演示，不连接真实接口或下载地址。
- 增加星光漂移、熊崽轻浮动、滚动渐入、手机轻微 3D 悬停、玻璃反光和章节进度动画。
- 支持系统“减少动态效果”设置，避免动画影响阅读。
- 完成 1920px、1440px、768px、390px 响应式适配，无横向滚动条。
