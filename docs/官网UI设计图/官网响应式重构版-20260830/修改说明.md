- 官网：`http://localhost:3001/design-preview/screen-only/index.html`
- 用户端展示组件：`http://localhost:3001/website-ui-preview`

## 本次实际修改

1. 将官网改为真实响应式 HTML、CSS 和本地组件结构，不再使用整张长图作为网页主体。
2. 保留蓝紫宇宙主视觉、熊崽品牌、使命文案、粉紫产品区、青绿色保障区及原有导航方向。
3. 三台手机拆分为金属外壳、内屏页面、黑色压边/暗角、玻璃反光/环境阴影四层，并复用本地真实用户端页面。
4. 左侧首页仅显示两个陪玩；中间展示陪玩主页；右侧完整显示四个订单，价格为 `¥25.00`、`¥30.00`、`¥45.00`、`¥60.00`。
5. 已移除手机状态栏、日期、服务时间、预约时段和分钟数；各页面人物图片互不重复。
6. 增加 iPhone、Android 和网页版三个本地演示入口，点击只显示“暂未开放下载”的本地提示，不连接真实接口或服务器。
7. 增加熊崽轻浮动、星光移动、滚动进入、轻微 3D 悬停和玻璃反光，并兼容系统“减少动态效果”设置。
8. 完成 1920、1440、768、390 宽度适配；无横向滚动条，桌面端没有右侧黑色空白。
9. 保留服务协议、隐私政策、联系入口、公司信息和版权信息位置。
