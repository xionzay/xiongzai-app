# 熊崽电竞官网像素级复刻版

## 实现结果

- 官网主画面以用户指定设计稿为唯一视觉基准，熊崽人物、宇宙背景、三台手机、渐变曲线、保障卡片和页脚保持一致。
- 页面会随浏览器宽度等比例铺满，已检查 1920px、1440px、768px 和 390px，没有右侧空白或横向滚动条。
- 在设计稿画面上增加真实的网页交互层：顶部导航、开始探索、章节跳转、三台手机、熊崽小助手、服务协议、隐私政策和下载按钮均可操作。
- 页面保留星光闪烁、传送台呼吸光、手机玻璃高光和顺滑滚动效果，并支持系统“减少动态效果”设置。
- 顶部及底部“下载 App”按钮会打开设备选择弹窗，包含 iPhone/iPad、Android 和网页版三个本地演示入口。
- 当前未连接真实接口、服务器、数据库或下载地址；点击下载后仅展示本地演示提示。
