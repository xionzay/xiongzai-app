# 熊崽电竞用户端三页面生成版

生成方式：内置图像生成工具，UI Mockup 模式。

## 页面内容

- `01-首页.png`：三位不同头像的陪玩卡片，价格分别为 ¥25、¥30、¥45。
- `02-陪玩主页.png`：小鲸的头像、评分、声音名片、个人介绍和两项服务，价格为 ¥25、¥45。
- `03-我的订单.png`：四个不同头像的订单，价格分别为 ¥25.00、¥30.00、¥45.00、¥60.00。

## 统一设计要求

- 熊崽电竞蓝紫品牌色与橙色价格、操作按钮。
- 暖白背景、圆角卡片、清晰信息层级。
- 不显示手机时间、电量、信号、日期、服务时间或预约时段。
- 所有人物均为虚构成年角色，页面之间尽量避免重复头像。
