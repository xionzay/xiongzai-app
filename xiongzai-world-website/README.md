# 熊崽世界 · 全新品牌官网

独立的新项目，仅完成本地预览。原官网与原发布身份保持不变；此目录没有托管登记或部署配置。

## 打开网站

当前预览：http://127.0.0.1:3020/

在本目录运行以下命令即可重新启动，无需安装前端依赖：

```sh
python3 -m http.server 3020 --bind 127.0.0.1 --directory dist
```

`dist/` 是完整静态网站。HTML、CSS、JavaScript 和所有图片均在项目内，不依赖旧网站服务器，也不请求第三方字体、脚本或图片服务。

## 内容与交互

- 浅蓝幻想首屏、浮空城堡、云海、独立鲸鱼、云端列车与熊崽。文字、导航、按钮、卡片均为真实网页元素。
- 八张独立 3:4 场景插画。卡片图片 600×800，详情图片 1086×1448，使用 WebP；卡片及详情按需加载。
- 场景弹层支持按钮、键盘左右键、Esc、移动端滑动；背景滚动锁定，关闭后恢复位置与焦点，Tab 焦点限制在弹层内。
- 关于、品牌价值、产品即将上线、世界邀请、加入与联系。邮箱为 `postmaster@xionzay.com`，支持 mailto、复制及失败时选中文本。
- 原生滚动，静置时持续轻柔动画。离屏、后台、弹层打开时暂停环境动画；尊重系统减少动态设置。未运行 JavaScript 时正文依然可见。

## 美术与动效边界

角色采用高品质图片及网页分层动画，没有真实 3D 模型或骨骼动画。坐姿角色与承托云层作为整体运动，不扭曲手脚。

列车使用独立透明素材，在远景进行短程滑行，增加云层承托，并避开文字和角色脸部。**这是一种简化的云端行进效果，尚不是沿背景弯曲轨道的精确透视运动。** 岛屿与建筑所在环境作为整体缓慢运动。

八张插画保留各自的主题环境与道具。露营图的邀请爪搭在身旁空座位上，海湾使用四弦尤克里里，雪原伙伴露出的脚底已修正为四枚蓝色趾垫。部分角色在构图中比需求建议的约三分之一更大，以保留小屏识别度。

美术来源记录在 `qa/asset-sources.json`，生成及针对性修正提示词在 `docs/`。原始生成 PNG 保存在主工作区 `output/world-website-assets-20260912/`，网页运行只需要本目录内的 WebP。

## 实际验证

使用本机 Chrome / Playwright 验证 1440、1024、768、390、320 像素宽度；检查截图、文字布局、图片比例、水平溢出与资源加载。

`qa/results.json` 记录八个场景逐一打开、切换、关闭、恢复焦点与滚动位置、手机触摸切换、邮箱复制及失败回退、离屏/后台暂停和减少动态设置。`qa/check.mjs` 为本机检查脚本。

`qa/performance.json` 记录桌面与手机视口各三轮来回滚动，以及 2.5 秒静置动画采样。该次本机采样的帧间隔中位数约 16.7ms，布局位移累计值为 0；桌面加载阶段记录一次 51ms 长任务。测试为本地、无网络和 CPU 限速的无头 Chrome，**不代表真机或公网性能保证**。

QA 脚本引用当前 Codex 环境的 Playwright 路径；在其他机器复测时可改为本机安装的 `playwright`。网站运行本身不需要 Playwright。

## 维护位置

- `dist/index.html`：正文、导航、卡片与弹层结构。
- `dist/styles.css`：配色、布局、响应式规则和动效。
- `dist/app.js`：场景文案、弹层交互、导航、动画暂停与邮箱复制。
- `dist/assets/`：网站运行使用的全部本地图片。

未添加虚构用户数据、下载链接、视频入口、社交账号、职位、地址或政策链接。正式发布需要另行确认新的网址及托管身份。
