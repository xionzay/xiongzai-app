# 阶段 5 实时能力说明

截至阶段 5 验收时，仓库中不存在可用的 WebSocket 网关、连接票据接口、实时服务应用或可核验的重连协议。

移动端因此通过 `ChatTransport` 抽象接入真实 HTTP 消息持久化接口，并只在 App 位于前台且网络在线时执行受控轮询。进入后台、离线或页面卸载后停止轮询；恢复前台或网络后重新拉取服务端事实并提交真实已读进度。客户端没有创建假的 Socket，也不会定时生成本地消息冒充实时消息。

上线阻断：若产品要求真正实时消息，需要后端先提供经过认证的 WebSocket 网关、连接票据、事件契约、重放/去重游标、心跳与限流约定。完成后可新增 `WebSocketChatTransport`，保持页面层不变。
