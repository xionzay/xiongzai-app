## 修改内容

保留原始 `path d` 字符串，不重描、不改造图案。利用实际线条邻近及包含关系，把轮廓、眼睛、嘴等内部细节放进同一组，然后对整组确定性随机重排。剔除源画布边缘已残缺的 32 组，不把半个图案移入画面中间。保留 261 个完整分组、662 条原路径，无新增或重复路径。

生成脚本：`scripts/build-chat-wallpaper.mjs`。运行 `node scripts/build-chat-wallpaper.mjs`，需要项目依赖及本机 Chrome。随机种子固定为 `20260905`，输出画布为 1440×3120。审计信息见 `chat-pattern-rearranged.manifest.json`。

应用中以 SVG 按宽度等比铺设，不拉伸图案；背景随可视容器保持稳定，不因聊天内容变长而放大。渐变不烧入图案，可单独修改颜色与线稿透明度。
